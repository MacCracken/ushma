## Gates (M1, `scripts/gates.sh`)

The oracle (`cargo test`, `--check`, clippy, `mpfr_ref.py`, `validate.py`, `probe_tables.py`, `cr_verify.py`,
`mathx_tables.py`, `vendor_fmtf.py`), `cyrius build`, `distlib --all` and `--check`, `cyrius test` on ELF,
`--bounds`, PE and aarch64, `bench`, `fuzz --poison --bounds`, `coverage --exec --min 80`, `fmt --check`, `lint`,
`doc --check`, `vet`, `deps --locked`, `audit`, `surface_parity.py` and `rust_test_ledger.py --check` all pass.

**Known upstream diagnostics** (from vendored `lib/`, never edited):
- `warning: large static data (137,984 bytes)` on every compile. This is sigil's crypto buffers,
  pulled in by sandhi → tls (`[lib.ai]`'s stack). prakash records the same diagnostic.
- `cyrius deps`: `refusing to overwrite stdlib leaf 'sakshi'`. hisab 3.4.1 declares an unused
  `[deps.sakshi]`; the stdlib copy wins, and the two are byte-identical (port plan §2.7, §8).
  Probe 10: every consumer's resolve warns too, until hisab drops it.
- PE only (`--win`): six `syscall N … is not routed on CYRIUS_TARGET_WIN=1; it returns -38` warnings
  in `lib/fdlopen.cyr` and `lib/dynlib.cyr` (sandhi's companions). Probe 10: a `[lib.ai]`
  consumer's PE build keeps one (`lib/dynlib.cyr:674`), and the POST still works on PE (probe 7).

`scripts/gates.sh` filters these, and any diagnostic located in `lib/`. ushma's own code must
add no diagnostic.
